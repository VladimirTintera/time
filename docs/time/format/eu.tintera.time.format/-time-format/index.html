TimeFormat

interface TimeFormat

Represents a configuration for formatting times.

This interface defines which components (hour, minute, seconds, milliseconds, am/pm) should be included in the formatted output and their respective styles.

Example:

val format = TimeFormat {
    hour = HourFormat.Auto.Numeric
    minute = MinuteFormat.Padded
}
